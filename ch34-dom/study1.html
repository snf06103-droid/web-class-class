자바스크립트의 객체 시스템

자바스크립트는 브라우저 자체를 객체로 이해하고 있으며 최상위 객체를 window 객체라고 부른다.

그리고 그 최상위 객체 window 아래에는 여러 객체들이 포함되어 있다.

  • document -> 정보들을 표현하는 문서객체
    • html 파일 그자체가 도큐먼트 객체이다.
  • location -> 웹페이지의 위치 정보를 표현하는 객체
  • history -> 이동했던 페이지들에 대한 정보를 관리하는 객체
  • console -> 개발자 툴에 있는 콘솔 객체 오류를 찾아주는 역할을 한다.
  • navigator -> 브라우저 정보를 담고 있는 객체
